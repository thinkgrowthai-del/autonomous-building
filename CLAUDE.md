# CLAUDE.md — Autonomous Building Technology website

Static marketing site for **Autonomous Building Technology**, an engineering firm that designs buildings that generate, store and manage their own energy (on-grid or fully off-grid). The site's job is to explain the offer, build credibility (research foundation, founder), and convert visitors through the contact form.

**Start every session by reading [MEMORY.md](MEMORY.md).** It holds the progress log, the owner's corrections and preferences, open TODOs and the next task. Update it at the end of any session that changes the site or receives new feedback.

**The content source is `complete content.pdf` (added 2026-10-04), the owner's latest full brief.** It supersedes `Website Note Pages.pdf` (the earlier version). Always diff the site against the newest PDF in the project root.
- Home, About, Services and Contact use the brief's copy, with light copyedits for grammar and typos marked `<!-- TODO: owner to confirm wording -->`.
- **Approach, Markets and Research are part-placeholder pages.** The latest brief adds real copy for each (the 5Zero concept, the place-based key points, the research key points); the rest is still drafted *only from facts elsewhere in the brief*, and each page's header comment says which parts are which.
- Never invent stats, testimonials, case studies, clients, publications, people, photos of real people or contact details.

**Design references:** https://www.epconsultenergies.com/ for structure and format, and https://rybka.co.uk/ for the calm, light, photography-led feel. When in doubt, choose the calmer option.

## Stack
- Plain HTML, CSS and vanilla JS, with **no build step for deployment**. Deploy the folder as-is, without `tools/`.
- Fonts: Google Fonts **Inter** for all text, and **Cinzel** only for the logo wordmark.
- Images: Unsplash URLs with a responsive `srcset` (`w=640/1024/1600/2000`). Before using a new ID, check it returns 200 and preview it. Some guessed IDs 404, and some don't show what you'd expect.
- Contact form: posts via `fetch` to Formspree (`YOUR_FORM_ID` placeholder in the contact fragment).

## Workflow rules
- **Header, footer and `<head>` changes:** edit `index.html`, then run `python tools/build.py`.
- **Inner-page content changes:** edit `tools/pages/<page>.frag.html`, then run `python tools/build.py`. Never hand-edit the generated pages.
- **Adding a page:**
  1. Create `tools/pages/<name>.frag.html`, including all the meta keys.
  2. Add the nav link in `index.html` (header and footer).
  3. Add the page to the `order` list in `build.py` and to `PAGES` in `seo_check.py`.
  4. Rebuild.
- **Domain:** `SITE_URL` is read from `<link rel="canonical">` in `index.html` and is `https://www.autonomous-building.co.uk` (confirmed 2026-10-04). If it ever changes, update the canonical link, `og:url` and the JSON-LD in `index.html`, then rebuild.
- **After any change:**
  - `python tools/seo_check.py`. It must print "All SEO checks passed."
  - `cd tools && npm install` (first time only), then `node tools/check.js [pages] [widths]`. Run it from **PowerShell**, because Edge/puppeteer fails inside the Bash sandbox. Use widths `360,390,768,1024,1440`. Expect `overflowX=0` and no console errors, then review the PNGs in `tools/screenshots/`.
  - `check.js` emulates `prefers-reduced-motion`, so its screenshots show static final states. To check the motion itself, serve the site over http, run a puppeteer script without that emulation, and scroll with `behavior: 'instant'`. The site sets `scroll-behavior: smooth`, which skews coordinates measured straight after `scrollIntoView`.
- **Lighthouse (mobile):** serve with `python -m http.server 8765` (start it from Bash in the background; `python` in PowerShell may be the Store stub). Then run `npx lighthouse@12 http://127.0.0.1:8765/<page>.html` with `CHROME_PATH` set to Edge.

## SEO rules
- Exactly **one `<h1>` per page**, and no skipped heading levels.
- Title ≤ 60 characters and meta description 70–160, unique per page. These are set in the fragment meta and in `index.html`.
- Every page needs canonical, `og:*` (`site_name`, `locale` en_GB, `url`, `title`, `description`, `image`) and `twitter:card`. `build.py` fills these in for inner pages.
- JSON-LD uses provided facts only:
  - home: `ProfessionalService` + founder `Person` with the ORCID
  - about: `Person`
  - services: `OfferCatalog`
  - inner pages: `BreadcrumbList`, added automatically
- Every `<img>` needs `alt`, `width` and `height` plus `srcset`/`sizes`. Hero and banner images use `fetchpriority="high"`; everything else uses `loading="lazy"`.
- `lang="en-GB"`. Use descriptive link text, never "click here".

## Mobile rules
- CSS is mobile-first, with breakpoints at 480 / 768 / 1024 / 1200. The desktop nav (7 links + CTA, tight 22px gaps) appears at ≥1200, and the full-screen menu below that. Check 1200px whenever nav items change.
- Touch targets ≥ 44px. **Form inputs use 16px text** so iOS doesn't zoom. Headings use `overflow-wrap` and `hyphens`. Wrap terms like `on-grid` and `off-grid` in `<span class="nw">` so they never split.
- No horizontal overflow at 360px.

## Design system (calm, Rybka-inspired; owner-approved)
- **Light and airy, with sections that alternate** (the owner asked for more contrast on 2026-10-01):
  - The section tones are white, `--bg-alt #EEF1F6` (cool grey-blue, deepened from #F5F6F8) and, **at most once per page**, a navy `.section--dark` band. Home uses it for 5 Zero.
  - **Never put two `--bg-alt` sections next to each other**, because the `.cta` block is `--bg-alt`.
  - Avoid three white sections in a row.
- **Copy style: no em dashes.** Use commas, colons, parentheses or two sentences instead. The owner reads dashes as "AI-sounding". A grep for `—` in `index.html` and `tools/pages/` should return nothing.
- Navy `#0A1F5C` / `#061338` for text and the footer. Gold `#D4A017` is used **sparingly**: primary buttons, `.label`, small rules, the Autonomy outcome tile and hovers.
- **Components:**
  - layout: `.hero` (single image, slow zoom), `.page-banner`, `.split`
  - home: `.hero__slides` (slow photo crossfade, fixed text, gold progress bars + pause button), `.system` ("six parts, one outcome": 6 icon tiles in a hairline grid, with a gold connector into a navy Autonomy tile; 3+bracket+tile at ≥1024px, stacked below that), `.teasers` (EP-style image cards), `.spotlight` (EP-style "where we work" region tabs that auto-advance), `.five-zero` ("Zero" written once, oversized and sticky; the five outcomes complete it, and the row mid-screen is highlighted), `.photo-band`
  - approach/markets/research: `.info-grid` (numbered or region cards, 1→2→3 columns), `.pill-list`, `.link-row`
  - services: `.tiers`/`.tier`, `.starter`
  - about: `.founder` + `.monogram`, `.team-list`
  - shared: `.cta` (one column at every width: the button sits directly under its question), `.btn--gold`/`.btn--line`, `.text-link`, `.label`
- **Header (owner, 2026-10-07/08): the gold wind turbine is at top left and the owner's EXACT logo is at top right. Never use a redraw.**
  - **Logo:** `assets/img/logo-full.png` (stacked lockup with the blue arc), `logo-mark.png` and `logo-word.png` are cut out of `Autonmous Building-Logo.png` with Pillow. The navy background is removed using the red channel for alpha, and the arc is lifted out as light. If the owner sends a new logo, re-cut it the same way.
  - **Two states:**
    - *First glance* (top of page): the turbine is scaled up with `transform: scale()` from its top-left corner (2.2× phones, 2.6× ≥768; at ≥1200 it is 3× **and** dropped 60px so the blades clear the nav row), and the full logo shows.
    - *Compact* (`.is-scrolled` from `main.js`, or `.is-open`): the turbine returns to 60/72px and the logo crossfades to the mark + lettering row.
  - **The scrolled/open bar is navy, not white,** because the logo's pale gold lettering disappears on white.
  - `--brand-reach` (150/175/296px) is the big turbine's bottom edge. The hero and `.page-banner` top padding use it so titles start below it.
  - The rotor spins at 4s (2s on hover); the owner asked for it bigger and faster.
  - The right logo link is `aria-hidden` + `tabindex="-1"`; the turbine link carries the accessible name.
  - At 1200–1349 the nav gaps are tightened. Check 1200px after any header change.
  - **One gold CTA per screen (2026-10-11, from the apple-design review):**
    - On Home the header "Talk to the team" is hidden (`visibility`, so the nav never shifts) until you scroll, because the hero has its own button. The rule is `body:has(.hero)`.
    - On Contact it's hidden too: on desktop it keeps its space; in the phone menu it's `display: none`.
    - Inner-page banners have no button, so the header one stays visible there.
- **Motion ("calm-alive", approved 2026-10-01).** The references feel alive because content changes on its own, not because of effects. The motion inventory is:
  - the hero crossfade (7s) and region spotlight (6s), both driven by `rotator()` in `main.js`
  - staggered list reveals (`.js-stagger`, `--i`)
  - unmasking `h2.reveal` headings
  - the `.system` tiles cascade, the connector draws into Autonomy, and its gold dot breathes
  - the page-banner zoom and entrance
  - parallax at ≥768px
  - quiet hovers
- **Motion rules:**
  - Rotators must stay slow and pausable: hover, off-screen, hidden tab, the pause button, and a click on a region tab stops it.
  - Everything respects `prefers-reduced-motion`, which shows the static final state with no rotation.
  - `h2.reveal` is clipped, so `main.js` observes its *parent*, because IntersectionObserver ignores fully clipped targets.
  - `main.js` applies every hidden starting state under `html.js-init`, which turns transitions off. Otherwise content would fade *out* at load. Keep any new starting-state setup before `js-init` is removed.
- **No busy effects:** no canvases, dashboards, shimmer, glows or textures. The 2026-09-29 "too busy" rejection still applies to everything except the two approved rotators. Don't speed them up or add per-slide headlines without the owner's OK.
